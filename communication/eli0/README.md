# ELI0

> **Explain Like I Have Zero Context.**

让 AI 面向一个“有正常理解能力，但没有前置上下文”的读者来解释内容。

ELI0 不是让 AI 把复杂内容讲得像给小孩听，也不是简单地少用术语。它更关注另一类常见问题：AI 经常默认读者知道项目背景、前序讨论、缩写含义和中间推理，于是文字看起来专业，实际却不容易理解。

ELI0 的核心原则是：

> 把理解当前内容所必需的最少隐含上下文写出来，同时保留原有事实、技术细节、限制条件和不确定性。

## 适合场景

- 解释技术概念或陌生领域
- Review 技术方案、设计文档和 README
- 重写抽象、黑话较多或依赖上下文的内容
- 检查总结、事故复盘或执行汇报是否真的能让新人看懂
- 让 Review 意见更具体、更容易执行

## 它不会做什么

- 不会把读者当成小孩
- 不会为了“通俗”删掉必要的技术细节
- 不会把所有回答都改成教程
- 不会编造缺失的背景、原因或项目历史

## 使用

安装后可以直接让 Agent 在合适的任务中使用，也可以显式指定：

```text
使用 ELI0 review 这份方案，找出一个第一次接触项目的人会看不懂的地方。
```

或：

```text
用 ELI0 rewrite 这段内容，保留原意和所有限制条件，但让它不依赖前面的聊天记录也能读懂。
```

真正的 Agent 指令见 [`SKILL.md`](./SKILL.md)。
